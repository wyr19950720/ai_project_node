# WorkMind AI 项目简介

WorkMind AI 是一个基于 FastAPI + LangChain + LangGraph 的大模型应用开发项目。

## 核心功能

- 智能对话：支持 DeepSeek 模型流式对话
- 知识库问答（RAG）：上传文档后基于向量检索回答问题
- 智能体（Agent）：基于 LangGraph 实现多步骤任务编排
- 工作流（Workflow）：可视化编排业务流程
- ERP 数据查询：对接企业资源计划系统数据

## 技术栈

- 后端：Python FastAPI
- 前端：Vue 3 + Vite
- LLM：DeepSeek
- Embedding：智谱 embedding-3 / SiliconFlow bge-m3
- 向量检索：内存向量库（余弦相似度）

## 固定知识库说明

本目录（server-py/knowledge_files/）下的所有 .txt / .md / .pdf 文件会在服务启动时自动加载进知识库，无需手动上传。
